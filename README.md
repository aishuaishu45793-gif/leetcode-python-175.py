# Python Programming Practice 🚀

## About This Repository

This repository contains a collection of Python programming practice projects developed to improve my coding skills, logical thinking, and problem-solving abilities.

These programs cover different Python concepts, including loops, conditional statements, strings, lists, mathematical operations, and basic algorithms.

## Programs Included

### 1. Strong Number Checker

Checks whether a given number is a Strong Number by calculating the factorial of each digit and comparing their sum with the original number.

### 2. Second Smallest Number

Finds the second smallest distinct number from a given list using Python lists, sets, and sorting.

### 3. Anagram Checker

Checks whether two strings contain the same characters in a different order.

### 4. Sum of Even Numbers

Calculates the sum of all even numbers in a given list.

### 5. Fibonacci Series Generator

Generates a Fibonacci series for the specified number of terms.

## How to Run the Programs

1. Install Python on your computer.
2. Download or clone the project repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the Python file:

```bash
python filename.py
```

Replace `filename.py` with the actual Python file name.
